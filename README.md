# JMU 夜间联网

适用于集美大学锐捷有线认证环境的 Windows 助手，提供普通认证、夜间认证方案、登录后自动认证及定时切换。

## 简要原理

程序通过 Npcap 在有线网卡上收发锐捷 802.1X 认证报文。夜间方案先使用办公区认证 IP 完成教育网认证，再使用网卡实际地址和所选运营商进行第二阶段认证；定时任务按断网时间提前尝试切换，并核对本次认证回应及有线联网结果。能否生效取决于校园网当前的认证策略。

## 使用条件

- **同一宿舍仅限一人使用**，多人同时运行会互相冲突。
- **必须用网线连接校园网有线端口**，可使用内置网口或 USB 转网口；仅连接校园 Wi-Fi **无法**使用此方案。
- 使用 Windows 10/11 x64，并持有可正常认证的校园网账号，无需绑定宽带账号也能使用。
- 安装 Npcap 并启用 WinPcap 兼容模式，确保程序能识别所用有线网卡；缺少驱动时会引导从官网下载。
- 夜间方案需要可用的办公区认证 IP；该地址已填在程序设置中。

## 下载使用

从 [Releases](https://github.com/KrasTB/jmu-network-unlock/releases/latest) 下载 Windows 压缩包，完整解压，双击 **JMU 夜间联网.exe**。首次填写自己的账号密码，无需安装 Python。

**npcap安装时勾选☑ Install Npcap in WinPcap API-compatible Mode**

- 未自动识别网卡时，在 **设置 → 认证网卡** 手动选择。
- **重新认证**按时段选择方案；**夜间认证**手动尝试夜间方案，期间可能短暂断网。
- “有线已连接”表示链路接通；“有线可上网 · 已验证”表示最近一次联网检测通过。进程运行和历史记录不等于当前能上网。

时间规则：周一至周四 23:00、周五至周日 24:00 起进入夜间时段，06:00 恢复；提前 8 分钟准备。06:00 后每半小时，若仍在使用夜间方案，会静默访问 `10.8.2.2` 并尝试恢复运营商；每天最多 4 次，认证及有线联网验证成功后即停止，失败则尝试回退夜间连接。已是运营商时保持原连接，其余正常时段不自动检测或重认证。关闭主窗口后仍由计划任务检查；到限制时段仍未确认夜间认证成功时，仅请求 Windows 右下角通知，同一次持续故障不重复提醒。系统通知设置可能隐藏提示。节假日文件需按学校通知维护，当前附表仅含 2026 年。

办公区认证 IP 默认 `172.20.1.10`，不同账号、端口及学校是否适用需实测，不保证绕过限制或无感切换。

密码保存在本机 `程序/config.txt`。运行日志为 `程序/runtime.log`，默认只记录关键事件和状态变化；当前文件与一份备份各限 512 KiB，合计约 1 MiB。排障时可在设置中开启“详细日志”，同样遵守容量上限。日志隐藏账号密码；反馈问题前仍请检查日志是否含不想公开的网络信息。

## 最简模式

在 **设置 → 最简模式（下次打开直接认证）** 中启用，窗口随即关闭。此后双击程序只做一次联网验证：已联网就退出，断网则按时段认证一次，用 Windows 右下角通知结果后退出。没有主窗口、测速、后台轮询或自动切换；缺少账号、驱动或网卡配置时才显示必要设置。

启用时会关闭本程序的自启动和定时任务。**按住 Shift 双击程序**可返回完整界面，取消最简模式后可按需重新启用自动功能；也可使用 `--full` 参数打开完整界面。

## 源码与构建

目录：`app/` 为界面和调度代码；`core/` 为认证核心的 Windows 移植源码；`tools/` 为构建工具；`tests/` 为离线测试。

GUI 构建需要 Windows x64、Python 3.12（含 tkinter）：

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-build.txt
# 从同版本发行包提取已验证的核心和 DLL；也可自行编译 core/。
.venv\Scripts\python tools\prepare_runtime.py --archive 路径\JMU-night-network-windows-x64-v0.1.4.zip
.venv\Scripts\python -m unittest discover -s tests -v
.venv\Scripts\python tools\build.py
```

构建输出在 `dist/`。从源码启动为 `.venv\Scripts\python app\launcher.py`。

认证核心构建见 [core/README.md](core/README.md)。GUI 的测试不会使用真实账号认证；发行包通过中文路径、首次设置、网卡选择、状态提示和打包启动检查，未覆盖所有硬件或其他学校环境。
